# CSV_STDIN

The `csv_stdin()` source allows AQL to query CSV_STDIN files using standard SQL-inspired syntax.

CSV_STDIN files are treated as tabular data sources, making them accessible through the same query interface used for Aegis data, databases, and other supported formats.
