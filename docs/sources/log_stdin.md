# LOG_STDIN

The `log_stdin()` source allows AQL to query LOG_STDIN files using standard SQL-inspired syntax.

LOG_STDIN files are treated as tabular data sources, making them accessible through the same query interface used for Aegis data, databases, and other supported formats.
